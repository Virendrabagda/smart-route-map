# Smart Route Map 🗺️

Smart Route Map is a web-based project that finds the shortest route between two cities using Dijkstra's Algorithm.

## Features

- Select From City and To City
- Find shortest route
- Calculate distance in km
- Calculate estimated travel time
- Cities and routes stored in MySQL
- FastAPI backend
- HTML, CSS and JavaScript frontend

## Technologies Used

- Python
- Dijkstra's Algorithm
- MySQL
- FastAPI
- HTML
- CSS
- JavaScript
